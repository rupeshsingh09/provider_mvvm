## 📌 About

This project demonstrates **MVVM (Model-View-ViewModel) architecture** in Flutter using **Provider** for state management.
It follows a clean and scalable structure suitable for real-world applications.

---

## 🚀 Features

* 🔹 MVVM Architecture implementation
* 🔹 State Management using Provider
* 🔹 Clean and scalable code structure
* 🔹 Separation of concerns (Model, View, ViewModel)
* 🔹 API integration (if used)

* 💙 Flutter
* 🎯 Dart
* 🔄 Provider
